1Gabarito

Envie o cartão “Gabarito de correção” de cada tipo de prova (PDF ou imagem). Se a prova tem Tipo A e Tipo B, são dois gabaritos: pode enviar os dois de uma vez ou um depois do outro.

Digitar ou corrigir o gabarito à mão

Uma questão por linha: número e resposta. C/E para certo/errado, A–E para múltipla escolha, os dígitos (ex.: 011) para numérica e X para questão anulada (todos ganham o ponto). Para mais de um tipo de prova, escreva TIPO A numa linha e o gabarito dela embaixo, depois TIPO B etc. Também aceita planilha (.xlsx/.csv) pelo botão acima.

Quanto vale cada item (igual para todos os tipos de prova)

ItensVale cada (acerto)Desconta (erro)
Itens tipo A — certo/errado
Itens tipo B — numérica
Itens tipo C — múltipla escolha

Em branco não soma nem desconta. Dupla marcação conta como erro.

Na imagem: contorno verde = certa, vermelho = errada, azul = resposta do gabarito. Se a leitura errou, corrija o campo “lido” (A+C para dupla, vazio para em branco). As linhas em amarelo são as de leitura duvidosa.
